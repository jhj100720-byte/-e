# 인터넷 상품 품질 인증 센터 (Product Quality Verification Center)

React 기반의 **인터넷 상품 품질 및 기업/공장 정품 분석 시스템** 프로젝트입니다.

## 주요 기능
- **이미지 업로드 & 라벨 분석**: 기업명, 공장명, 정품 시리얼이 포함된 상품 사진 스캔.
- **AI 판별 엔진 모의 동작**: 이미지 OCR 파싱 및 정품/가품 신뢰도 스코어링.
- **디지털 품질 인증서 연동**: 판별 완료 시 모바일/웹 전용 디지털 인증서 출력.
- **최근 검증 이력 관리**: 실시간 스캔 히스토리 필터링 및 관리.

## 시작하기

```bash
# 패키지 설치
npm install

# 개발 서버 실행
npm run dev
```

브라우저에서 `http://localhost:5173` 접속 후 사용하실 수 있습니다.
